# Source code Back-end dự án cá nhân: clone Trello web

## VuVanDao

source code dự án Trello , dự án quản lí lịch làm việc 1 cách trực quan, dễ dàng sử dụng và tiếp cận dựa vào Board, card, list
dự án phục vụ mục đích học tập tìm hiểu, luyện tập kĩ năng cá nhân

## Tổng quan

- Kiến trúc : layered Architecture ( 4 - layered)
- Ngôn ngữ : javascript
- Framework : NodeJS, ExpressJS, Socket.io
- version control : Git, Github
- deploy : render ( vì chưa có tiền :( ))
- Kiểm thử : Postman
- Bảo mật : Jsonwebtoken
- Cơ sở dữ liệu: MongoDB
